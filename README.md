# ОКРУГ

Официальный одностраничный сайт барбершопа «ОКРУГ» в Калининграде.

[Открыть сайт](https://okrug-kaliningrad.suredkek.chatgpt.site)

## Что есть на сайте

- услуги и актуальный прайс;
- мастера, работы и отзывы;
- адрес, режим работы и контакты;
- адаптивная версия для телефонов;
- онлайн-запись через YCLIENTS или Яндекс Карты;
- SEO-разметка и превью для социальных сетей;
- подключение Яндекс Метрики по ID.

## Запуск

Понадобятся Node.js 22.13 или новее и pnpm 11.

```bash
pnpm install
pnpm dev
```

После запуска сайт будет доступен по адресу `http://localhost:3000`.

## Настройки

Создайте `.env.local` на основе `.env.example`.

| Переменная                       | Назначение                                          |
| -------------------------------- | --------------------------------------------------- |
| `NEXT_PUBLIC_SITE_URL`           | Адрес сайта для SEO и социальных сетей              |
| `NEXT_PUBLIC_YCLIENTS_WIDGET_ID` | ID виджета YCLIENTS; можно оставить пустым          |
| `NEXT_PUBLIC_YANDEX_METRIKA_ID`  | Числовой ID счётчика Метрики; можно оставить пустым |

Файлы `.env*` не попадают в Git. В репозитории хранится только безопасный пример `.env.example`.

## Основные файлы

- `app/page.tsx` — тексты, цены, ссылки и структура страницы;
- `app/globals.css` — оформление и адаптивная версия;
- `app/layout.tsx` — SEO-метаданные;
- `public/images` — фотографии;
- `public/og.png` — изображение для публикаций в соцсетях.

## Проверка перед публикацией

```bash
pnpm lint
pnpm build
```

## Загрузка на GitHub

Создайте пустой репозиторий без README и лицензии, затем выполните:

```bash
git remote add origin https://github.com/USERNAME/okrug.git
git push -u origin main
```

Замените `USERNAME` на имя аккаунта GitHub.
