# ОКРУГ — версия для GitHub Pages

Все файлы сайта находятся в одной папке. Установка зависимостей и сборка не нужны.

## Публикация

1. Создайте публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы из этой папки.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch.
5. Выберите ветку main, папку /(root) и нажмите Save.

Главная страница — index.html. Не переименовывайте изображения.
